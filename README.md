# 🛍️ Retail Sales Analytics Dashboard

## 📊 Project Overview

A professional Retail Sales Analytics Dashboard designed to monitor
sales performance, store performance, customer activity, returns,
and product sales.

The dashboard provides an interactive management view of retail
operations using dynamic KPIs, filters, comparisons, and detailed
sales analysis.

---

## 🎯 Project Objectives

- Monitor daily sales performance
- Track Month-to-Date (MTD) sales
- Compare sales performance with previous periods
- Analyze sales by store
- Monitor customer count
- Analyze average basket
- Track returns by store
- Identify top-selling products
- Compare sales including and excluding tax
- Provide interactive business analysis

## 🔎 Dashboard Features

### Daily Sales Report

Provides detailed store-level analysis including:

- Store Name
- Total Sales Including Tax
- Total Sales Excluding Tax
- Quantity
- Customer Count
- Basket Size

### Store Performance

Interactive analysis of sales contribution and performance across stores.

### Product Analysis

Identifies the Top 10 Products based on sales performance.

### Returns Analysis

Provides visibility into return amounts by store.

### Date Analysis

Users can select a specific date range to dynamically update the dashboard.
